# Trans MaK — MVP1 Démo

Aperçu interactif de la plateforme digitale Trans MaK pour la gestion et le suivi des transports de marchandises par camion.

## Contenu

- Site public
- Espace client (commande + suivi GPS + factures)
- App chauffeur PWA (workflow guidé + OTP)
- Tableau de bord admin (KPIs, GPS temps réel, facturation)

Démo cliquable — état persistant en localStorage.
